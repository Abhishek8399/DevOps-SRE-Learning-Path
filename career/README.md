The remaining `*-primer.md` files are focused chapters for the same system: read the relevant chapter, perform the bounded local exercise, record evidence, and defend the trade-offs in the interview playbook. Reading a chapter or marking it finished never raises mastery.

## Evidence boundary

```text
reading -> understanding claim
local lab -> bounded execution evidence
reviewed artifact -> transferable engineering evidence
production/on-call result -> real-world evidence
```

Do not collapse these levels. When a runtime is unavailable, use a clearly labelled model or simulation and state what remains unproven.
