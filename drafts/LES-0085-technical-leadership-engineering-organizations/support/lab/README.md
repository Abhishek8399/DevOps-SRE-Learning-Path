# LES-0085 guarded engineering-leadership review lab

This offline lab reviews one fictional checkout-platform leadership packet. It performs no HR, messaging, ticket, calendar, provider, production, network, employee-record or performance-management call. People, workload, outcomes, points and scores are teaching inputs, not organizational or learner evidence.

Run from this directory in Ubuntu 24.04 as a normal user:

```bash
bash lab.sh doctor
bash lab.sh setup
bash lab.sh status
bash lab.sh roadmap
bash lab.sh priorities
bash lab.sh delegation
bash lab.sh decisions
bash lab.sh stakeholders
bash lab.sh load
bash lab.sh evaluate everything-priority-one
bash lab.sh evaluate responsibility-without-authority
bash verify.sh
```

The model has one defensible baseline and one isolated failure for each of 72 leadership gates. Five calculations expose capacity and reserve conservation, complete delegation contracts, decision deadline closure, consistent stakeholder views over canonical facts, and bounded on-call load spread with acknowledged handoffs.

The guard refuses root, cloud/runtime/people-system/messaging authority, symlinks, wrong ownership and unknown artifacts. It creates one UID-scoped directory containing a sentinel and two copied fictional JSON fixtures. Cleanup removes only those exact files and proves the directory absent.

Independent practice requires reviewer-owned fictional or sanitized scenarios with hidden outcome, authority, capacity, stakeholder, conflict and ethics changes. Never place employee records, performance feedback, employer incidents, customer data, credentials, private communications, internal strategy or confidential decisions in this repository.
